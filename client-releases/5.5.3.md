# GymPASS 5.5.3

- Selector de código de país para el WhatsApp del socio, con Bolivia (+591) por defecto.
- Correcciones de sincronización de planes por vencer y gestión de personal en la copia móvil.
- Credencial descargable y botones adaptados a pantallas estrechas.
- Aplicación Android, instalador y portable Windows actualizados a 5.5.3.

Android conserva el paquete y certificado de las versiones anteriores y utiliza código 5530. Windows x64 requiere Windows 10 o posterior; distribución sin firma de código.

Descargas: `GymPASS-Android-5.5.3.apk`, `GymPASS-Setup-5.5.3.exe` y `GymPASS-Portable-5.5.3.exe`. Huellas en `GymPASS-5.5.3-SHA256.txt`.
