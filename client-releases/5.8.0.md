# GymPASS 5.8.0

- Android usa código 5800, conserva el paquete y la firma existentes e incluye la interfaz web 5.8.0.
- Windows x64 incluye el instalador NSIS con Electron 45.0.0.
- Los binarios no tienen firma de código de Windows; sus huellas SHA-256 están en `GymPASS-5.8.0-SHA256.txt`.

Descargas: `GymPASS-Android-5.8.0.apk` y `GymPASS-Setup-5.8.0.exe`.
